# Приёмка опросов — шаг 24

Проверка критериев опросов из [`workflow-service/servey-task.txt`](../../workflow-service/servey-task.txt) на локальном стенде. Backend и Web проверялись только как зависимости приёмки; файлы этих проектов не менялись.

## Среда

- Backend: локальный API на порту `3002`, PostgreSQL 15 в одноразовом Docker-контейнере. База тестовая, без пользовательских данных; все миграции, включая схему опросов, применены.
- Web: временная копия `kcell-service-front` на порту `5173`, направленная на локальный API. Рабочая копия Web не изменялась.
- Mobile: debug-сборка приложения на Android Emulator с API 35. API-адрес эмулятора — `10.0.2.2:3002`.
- Для сценариев созданы отдельные временные учётные записи администратора и клиента, офис и опросы в одноразовой БД. Пароли и токены в этом документе не сохраняются.

- `npm run check` не прошёл: TypeScript и 259 тестов прошли, полный ESLint остановился на трёх прежних предупреждениях `require()` в `lib/widgets/publish.ios.ts:30–32`. ESLint изменённых файлов прошёл без замечаний.

## Итог и ограничения

Основной пользовательский путь опроса подтверждён живым backend на Web и Android. Приёмка не закрывает Web-экран результатов, ручную проверку состояний ошибок и пустых списков, а также доставку настоящего push: нужны исправление маршрута в Web и отдельная среда с push credentials. iOS не проверялся; для этого проекта используется Android-эмулятор.
