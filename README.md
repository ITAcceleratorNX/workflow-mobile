# Проверка качества и ручной регресс

В корне `workflow-mobile`:

```bash
npm ci
npm run check
npm run export:production
```

`check` генерирует актуальные типы Expo Router, проверяет TypeScript всего приложения,
запускает ESLint для всего репозитория (включая `hooks`, `context`, `lib`, `stores`)
с нулевым допуском предупреждений и выполняет тесты. Генерируемые `.expo/` и `dist/`
не входят в lint. `test` использует Node с загрузчиком `tsx` без отдельного IPC-сервера.

`export:production` создаёт минифицированные Hermes-бандлы iOS и Android в `dist/`.
Это проверка JavaScript-сборки; подпись, компиляция нативных проектов и установка
release-сборок на устройства проверяются отдельно. Перед сборкой проверьте,
что `EXPO_PUBLIC_API_BASE_URL` указывает на нужное окружение.

## Подготовка ручной проверки

Используйте тестовое окружение и отдельные аккаунты клиента, исполнителя,
офис-менеджера, администратора офиса и руководителя. Повторите основные сценарии
на iOS и Android, в светлой и тёмной теме. Для проверки гонок включите ограничение
скорости сети; для проверки ошибок временно отключите сеть. Пункты ниже пока не
отмечены: их нужно выполнить на устройствах.

## Чеклист

- [ ] **Регистрация клиента.** Выберите офис, существующую компанию и вариант «Другое»;
  завершите SMS-подтверждение и отправку. После смены офиса доступны только его
  компании, запрос содержит правильную роль и числовой ID офиса. Ошибки пароля и SMS
  отображаются, повторная отправка работает.
- [ ] **Регистрация исполнителя.** Выберите офис и категорию, отправьте заявку.
  Быстро смените офис дважды на медленной сети: поздний ответ первого офиса не
  подменяет категории последнего.
- [ ] **Настройки и тема.** Откройте «Настройки → Календарь», вернитесь назад.
  Авторизованный пользователь видит экран календаря; гостю показывается сообщение
  об ограничении. Переключите темы: текст, фон и иконки карточки настроения читаемы.
- [ ] **Здоровье и сон.** Откройте экран с пустой историей, затем добавьте записи сна
  и настроения. Блок динамики появляется без ошибки порядка хуков. Проверьте
  автоматическую и ручную норму воды, открытие оценки сна, закрытие и повторный вызов.
- [ ] **Списки задач.** Подготовьте задачи на вчера, сегодня, завтра, без срока и
  завершённую задачу. «Входящие» содержат все незавершённые; «Сегодня» — только
  незавершённые со сроком на текущий день в Asia/Almaty. Проверьте оба направления
  сортировки по созданию, сроку и приоритету; задачи без срока идут последними при
  сортировке по сроку. Настройки сортировки двух вкладок независимы.
- [ ] **Гонки и пагинация задач.** На медленной сети быстро переключайте вкладки и
  сортировку, затем догрузите несколько страниц. Последний выбор сохраняется,
  старые результаты и ошибки не возвращаются, дублей нет. Во время загрузки выйдите
  из аккаунта: данные прошлого пользователя исчезают. Вернитесь после смены дня:
  вкладка «Сегодня» обновляется.
- [ ] **Создание и детали задачи.** Задайте название, срок, время, повтор, приоритет
  и получателя. Закройте форму без сохранения и откройте заново: черновик очищен,
  значения по умолчанию соответствуют текущей вкладке. Сохраните задачу, измените
  название и приоритет, отметьте выполнение, снова откройте детали.
- [ ] **Календарь и жесты.** Переключите день/неделю/месяц, отметьте задачу выполненной.
  Анимация отметки работает, прокрутка не сбрасывается неожиданно. Откройте шторки
  задачи и срока, закройте свайпом и кнопкой. Клавиатура скрывается после закрытия,
  новая форма не наследует её высоту или открытый вложенный выбор.
- [ ] **Поиск получателей и команды.** Введите имя, сразу измените запрос, затем
  смените офис/компанию или закройте поиск. Показываются только результаты последнего
  запроса. Строка короче двух символов очищает результаты. Выберите руководителя и
  участников, сохраните команду и проверьте её после повторного открытия.
- [ ] **Создание заявки.** Выберите офис, блок, этаж и помещение, категорию и
  исполнителей. Смените офис и блок: зависимые поля сбрасываются, старые справочники
  не возвращаются. Проверьте обычную, плановую и повторяющуюся заявку, включая демо.
- [ ] **Работа с заявкой.** Под соответствующими ролями откройте редактирование,
  принятие, отклонение и назначение исполнителей. Закройте форму с несохранёнными
  изменениями и откройте другую заявку: её поля заполнены корректно. При смене офиса
  в принятии категории и исполнители относятся к новому офису. Проверьте сохранение,
  ограничения ролей, добавление/редактирование/удаление комментария.
- [ ] **Бронирования.** Выберите офис, дождитесь комнат, создайте бронирование,
  откройте QR-код и отмените бронирование. Быстро переключите фильтры «Моих
  бронирований» и догрузите страницы: остаются записи последнего фильтра. Повторите
  в демо. Неверный ID бронирования показывает ошибку, а не бесконечный индикатор.
- [ ] **Администрирование.** В списках пользователей меняйте роль, офис и компанию;
  откройте подряд двух пользователей, измените роль клиента на исполнителя и обратно.
  Категории, данные и компании соответствуют выбранному пользователю. Проверьте
  редактирование регистрационной заявки, компании и шаблона локации; повторное
  открытие формы восстанавливает сохранённые значения.
- [ ] **Умный офис и статистика.** Смените офис на медленной сети: комнаты,
  пользователи и привязки относятся только к выбранному офису. Откройте статистику
  каждой роли, обновите жестом; у руководителя проверьте аналитику и экспорт файла.
  После ошибки сети восстановите соединение и повторите загрузку.
- [ ] **Новости, поддержка и уведомления.** Откройте список и карточку новости,
  поставьте реакцию. Администратором создайте запланированную новость и проверьте
  дату. Откройте обращение поддержки и отправьте сообщение. В уведомлениях проверьте
  догрузку, отметку прочтения и переход к заявке; из push — переход к задаче при
  открытом, фоновом и закрытом приложении.
- [ ] **Общие состояния.** Pull-to-refresh завершается и не оставляет перекрытие
  поверх экрана. Toast закрывается по таймеру и кнопкой, несколько уведомлений не
  ломают интерфейс. При отключённой сети индикаторы завершаются, доступны предусмотренные
  экраном повторные действия. После выхода и входа другим пользователем не остаются
  старые данные и черновики.
- [ ] **Release на устройствах.** Соберите и установите подписанные iOS/Android
  release-сборки через обычный процесс проекта. Проверьте холодный старт, вход,
  возврат из фона, push, камеру/вложения, геолокацию и сохранение настроек после
  перезапуска. Если EAS Update настроен, проверьте получение и применение обновления;
  без EAS Update не должно появляться ложного предложения обновиться.

   ```bash

   ```

2. Start the app

   ```bash
   npx expo start
   ```

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **app-example** directory and create a blank **app** directory where you can start developing.

## Қазақша

Сіздің Expo қолданбаңызға қош келдіңіз 👋

Бұл [`create-expo-app`](https://www.npmjs.com/package/create-expo-app) көмегімен жасалған [Expo](https://expo.dev) жобасы.

### Бастау

1. Тәуелділіктерді орнатыңыз

   ```bash
   npm install
   ```

2. Қолданбаны іске қосыңыз

   ```bash
   npx expo start
   ```

Шығарылымда қолданбаны ашу опцияларын таба аласыз

- [дамыту құрастыруында](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android эмуляторында](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS симуляторында](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), Expo көмегімен қолданбаны әзірлеуді сынауға арналған шектеулі құмсауыт

**app** каталогындағы файлдарды өңдеу арқылы әзірлеуді бастай аласыз. Бұл жоба [файлға негізделген маршруттауды](https://docs.expo.dev/router/introduction) пайдаланады.

### Жаңа жобаны алыңыз

Дайын болған кезде, іске қосыңыз:

```bash
npm run reset-project
```

Бұл команда бастапқы кодты **app-example** каталогына жылжытады және әзірлеуді бастауға болатын бос **app** каталогын жасайды.

### Толығырақ

- [Expo құжаттамасы](https://docs.expo.dev/): Негіздерді үйреніңіз немесе біздің [нұсқаулықтармен](https://docs.expo.dev/guides) кеңейтілген тақырыптарға кірісіңіз.
